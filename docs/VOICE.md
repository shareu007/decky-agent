# 语音输入

v0.1.2 增加语音转文字输入，v0.1.5 增加 ChatGPT 账号转写，保持简洁界面：输入框旁只有一个麦克风按钮。识别文字会填入原有输入框，**不会自动发送或执行任务**。

## 配置与使用

1. 打开插件的“设置 → 高级设置”，启用“语音输入”。
2. 使用 ChatGPT 账号时，语音 API 地址留空即可，无需填写额外密钥或转写模型。使用独立 API 时填写转写模型。使用 OpenAI 时，当前官方文档推荐 `gpt-transcribe`；其他服务填写其实际支持的模型名称。独立 API 转写使用 `POST /audio/transcriptions`，与聊天模型分开。
3. 自定义 API 模式中，“语音 API 地址”留空时使用当前聊天 API 地址和密钥；若填写独立地址，需要单独填写语音密钥。**独立地址不会自动收到聊天密钥**。兼容的局域网 Whisper 服务也可作为转写端点；不是所有聊天代理都提供语音接口。
4. 保存后，点击输入框旁的麦克风开始录音；点击“结束转写”停止录音并转写。文字会追加到输入框，可以编辑后再点击发送。
5. 点击取消可停止当前录音或转写。关闭面板或切换会话也会清理本次录音，迟到的识别结果不会填入其他会话。

## 录音与数据

- 后端以普通用户调用系统 PipeWire 的 `pw-record`（或 `pw-cat --record`），使用系统默认输入设备，不依赖 Steam CEF 的网页麦克风权限。
- 输出为 16 kHz、单声道、16 位 PCM WAV。单次最多录制 60 秒；达到上限后停止麦克风，等待你点击转写。未提交的录音再保留最多 60 秒后自动删除。
- 临时文件位于 Decky 插件运行目录的 `speech/` 下，文件权限为 `0600`。转写成功、失败或取消后都会清理；插件重载会清理遗留临时录音。
- 点击“结束并转写”后，音频会发送到当前 ChatGPT 账号的官方转写端点或你配置的独立转写服务。模型服务的鉴权和收费按该服务自身规则执行。
- 未启用语音输入时不会启动录音。录音或转写期间阻止同时发送 Agent 任务和修改连接配置。

## 测试范围

已使用合成 WAV 进程和本机模拟 API 验证录音、停止、时长上限、上传、凭据隔离、重复请求、取消和文件清理。前端测试覆盖导航后迟到结果、取消转写，以及识别文字只填入草稿。浏览器预览使用模拟录音，不访问本机麦克风。

已在 Bazzite 测试设备上通过已安装的 Decky 后端录制约 3 秒真实麦克风音频，验证 16 kHz 单声道 WAV、multipart 上传和文件清理。测试仅使用本机临时接口返回固定文字，没有调用外部语音服务或验证实际识别准确率。修复了该设备 PipeWire 在正常 SIGINT 停止后返回退出码 1 的兼容问题；只有主动停止且 WAV 完整时才接受该退出码，空音频、不完整文件和意外退出仍会失败。

v0.1.5 在设备上使用已登录 ChatGPT 账号，将合成短语音成功转写为预期文本；录音麦克风链路仍使用已验证的 PipeWire。账号语音通过 Codex 的后端兼容 RPC 临时取得凭据，只发送到固定的 `https://chatgpt.com/backend-api/transcribe`，不读取 `auth.json`，不把令牌返回前端，不跟随重定向。该通道参考官方 Codex 语音实现，并经过当前账号实测；服务端权限或接口变化时会明确报错，也可使用独立语音 API。当前没有内置离线识别模型，也没有语音播报。

v0.1.6 修复 Decky 冻结运行时缺少 CA 路径导致的 HTTPS 证书校验失败，并修复迟到状态轮询取消转写的前端竞态。之前独立 Python 测试通过不足以证明安装后的 Decky 进程可转写；新增回归脚本直接调用已安装插件，见 [测试与复现说明](TESTING.md)。

参考：[OpenAI 文件转写文档](https://developers.openai.com/api/docs/guides/speech-to-text)、[PipeWire pw-cat/pw-record 手册](https://docs.pipewire.org/page_man_pw-cat_1.html)。
