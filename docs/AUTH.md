# ChatGPT 账号登录

支持通过官方 Codex app-server 的设备码流程登录 ChatGPT。对话、登录状态和设置保留在 Decky 侧边栏内，账号密码在 OpenAI 官方网站输入。

## 使用

1. 打开 **Decky → Decky Agent → 设置**，引擎选择 **Codex**，连接方式选择 **ChatGPT 账号**。
2. 点击 **登录 ChatGPT**。插件保存当前配置，显示一次性授权码和 `https://auth.openai.com/codex/device`。
3. 用手机或电脑打开该官方地址，登录账号并输入侧栏显示的授权码。若提示设备码登录未启用，请先在 ChatGPT 安全设置或工作区权限中启用。
4. 等待侧栏自动显示已登录账号。输入框下方和设置中提供模型菜单，可选择自动或指定模型。目录来自 Codex，实际使用权限以账号为准。
5. 设置工作目录，点击保存返回侧栏对话，即可发送任务。账号权益、可用模型和使用额度以 OpenAI 当前实际提供的内容为准。

等待授权时可取消；本插件最多等待 10 分钟。关闭侧栏后等待仍会继续，重载或卸载插件会取消待完成的登录。登录完成后凭据保留，重启插件会重新读取登录状态。退出登录可在相同设置区域操作，任务运行时需先停止任务。

## 与 API 模式的关系

- ChatGPT 模式使用官方 `openai` provider，不使用自定义 API 地址或聊天 API Key，也不把账号访问令牌发给自定义服务。
- 自定义 API 模式保留原来的地址、密钥和模型。其 Codex provider 明确不使用 OpenAI 账号鉴权。
- 两种模式分别保存模型选择。旧版本的设置和会话迁移为 API 模式，不会自动改变其鉴权方式。
- 切换登录方式或重新登录账号时，有消息的对话需要新会话；界面登录操作会在需要时新建会话。旧会话仍保留在历史中。
- ChatGPT 模式下，语音 API 地址留空时默认复用登录账号，访问固定的官方转写端点。填写独立语音 API 地址时仅使用单独的语音 API Key，不会将账号凭据发往该地址。

## 凭据与测试

官方 Codex 在插件专用 `CODEX_HOME` 的 `auth.json` 中保存凭据并自动处理刷新；该目录位于 Decky 插件运行目录下，独立于用户自己的 `~/.codex`。插件不读取该文件内容，也不将凭据传入前端或记录到会话。按文件凭据方式使用，不能阻止同一系统用户下的其他进程读取。

测试覆盖官方 provider 选择、环境密钥隔离、设备码响应、提前到达的完成通知、错误、超时、取消、退出、重启恢复、模型分页、旧配置迁移和账号切换后的会话隔离。设备测试成功获取并取消真实官方设备码；完整账号登录与真实模型调用需要用户本人完成授权后验证。

参考：[官方账号认证说明](https://learn.chatgpt.com/docs/auth)、[Codex app-server 认证接口](https://learn.chatgpt.com/docs/app-server#auth-endpoints)。
